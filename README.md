# MIRRORSCALE · 明镜心理（Horror Experience）

> **MIRRORSCALE** — *a 24-question psychological self-assessment that stops assessing you.*

一个**单文件**的网页恐怖体验：开场是标准的心理健康自评网站，24 道题之内逐步崩坏，BGM 从舒缓铺到崩坏，最后以一场**注定失败的挣扎**把你夺舍。

- 打开方式：双击 `index.html`（或拖进浏览器）。无需服务器、无需联网、零依赖。
- 建议：**戴耳机**、全屏、关灯。全程有实时合成的 BGM 与音效（无任何音频文件）。

## 剧本身份

页面伪装成「明镜心理 · 在线自评中心」的 PHQ-9 扩展量表：24 题、进度条、系统日志、自动生成报告。随题号推进，五层变质：

| 阶段 | 题目 | 画面 | 故事 | BGM |
|---|---|---|---|---|
| 0 正常 | 1–4 | 冷蓝白、圆角、青绿 | 标准抑郁/焦虑问询 | 54 BPM，Am9→Fmaj7→Cmaj7→G6 三角波铺底 + 正弦琶音，混响很湿 |
| 1 失真 | 5–8 | 纸张、衬线、卡片歪 0.3° | 房间、被移动的东西、有人看着你 | 58 BPM，和声开始加 b9、三全音，滤波器打开 |
| 2 走样 | 9–12 | 褪色、颗粒、暗红、红点录制 | 有人叫你名字、记忆空白、麦克风授权 | 62 BPM，半音聚集，脉冲低频进入 |
| 3 侵入 | 13–17 | 全黑、扫描线、故障字、心跳 | 房间对不上、头发被拨开、屏幕里有张脸 | 68 BPM，锯齿波、失谐、失真墙初现 |
| 4 恐吓 | 18–24 | 无卡片，只剩文字与黑暗中的脸 | 「你身后有什么？」→ 数三下 → 爆发 | 76 BPM，六音半音簇、饱和失真、随机尖啸 |

## BGM 怎么做的

一条实时生成的音轨，不是循环播放的文件：

- **和声**：每阶段一套四小节进行，从 Am9 这种协和和声，逐步替换成半音堆叠（A / Bb / B 同时响），到第 4 阶段是六音半音墙。
- **配器**：三角波铺底 → 锯齿波；正弦琶音 → 颤音；低通截止随阶段从 320 Hz 开到 1.2 kHz（越听越亮、越刺）；每个音都有 ±(2+8×阶段) 音分的失谐，越高阶段拍频越恶心。
- **节奏**：54→76 BPM 的脉冲低频，第 3 阶段起变成心跳式双拍。
- **空间**：程序生成的 2.7 秒卷积混响（噪声脉冲），所有铺底与琶音都过混响。
- **响度**：`TRIM = [1.45, 0.48, 0.55, 0.67, 0.76]` 这张表把各阶段总线配平过——开局听得清但不吵，后面炸但不至于刺穿耳膜。
- **夺舍段**：BPM 拉到 126，铺底变成上滑锯齿 + 带通扫频，9.5 秒的 riser 一路顶到黑场。
- **结束**：黑场之后切成**摇篮曲**——48 BPM 的八音盒动机（失谐 7 音分）+ 低音铺底，甜美又不对劲，最后 5 秒淡出。

想改音色/和声：`BGM` 模块里的 `HARM`（和声表）、`BPM`、`TRIM`、`pad()`、`arp()`、`pulse()`。

## 结局：夺舍

报告页选「往左看」→ 最后一幕 → 「可以 / 不可以」→ **无论选哪个都开始被夺舍**：

1. **意识条**：顶部出现 `意识 100%`，持续下跌。
2. **挣扎**：屏幕中央有「挣 扎」按钮，玩家可以疯狂点击（点哪都算），每次点击会把意识条顶回一点、留下红色涟漪；但上限一直在往下滑，所以**永远赢不了**。点多了按钮会躲开鼠标、改字（让 我 出 去 → 不…… → 没有反应。），最后彻底失效。
3. **手不听话**：指针被"拽"向画面中心（`--pull` 变量把光标位置拉偏，最多 66%），点哪儿都不太对。
4. **它的台词**：`它进来了。`→`手，先借我用一下。`→`林小满，别挣扎。`→`你不是第一个。`→`也不会是最后一个。`→`已经结束了。你只是还没承认。`
5. **夺舍完成**：黑色眼睑合上 → 再睁开时，网站已经被接管：「明镜心理 · **已接管**」「不需要你同意」「你的身体很合适。里面很安静，我喜欢。」，底下有一行小字：「（我还在。听得见吗。）」
6. **它的问卷**：只有 1 题，「你」现在是谁？——选项「我 / 不是我」，而「我」会自己亮起来，「不是我」变灰。你连答都轮不到。
7. **最后**：黑场，心跳，三行字：`你的手很适合我。` / `明天早上，你会照常醒来。` / `只是醒来的那个人，不是你。`，然后是一句很轻的「（放我出去。）」

## 其它机关

- **真的会读你的东西**：时区、屏幕分辨率、语言、钟点、每题停留秒数，都会出现在系统日志和报告里（纯本地，不上传）。
- **名字**：第 1 题问你怎么称呼，之后它就用这个名字叫你；报告、夺舍台词、结局都用。
- **假授权弹窗**：第 13 题弹出「想访问你的麦克风」，允许/拒绝都有对应台词。
- **脸是画出来的**：Canvas 逐像素渲染，会眨眼、呼吸、瞳孔跟随鼠标；湿发垂在脸上，手从画面底部摸上来。
- **报告是伪造的**：「被注视感 ∞」「回头意愿 0」「说谎倾向 100%」，以及用你真实数据拼的 4 处「不一致」；按「关闭页面」会变成「关不掉。」
- **指针位置**：平时也略有偏移，夺舍段被强行拉向中心。

## 操作

- 鼠标点选；键盘 `1`–`4` / `A`–`D` 也可选。
- 打字过程中点一下跳过逐字动画。
- 黑场后按**任意键**看报告。
- 夺舍段：**点哪里都算挣扎**（但没用）。
- 系统开了「减少动态效果」时，爆发段不会闪白。
